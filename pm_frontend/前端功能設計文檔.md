# 專案管理系統 — 前端功能設計文檔

> 代碼目錄：`project_management_service/pm_frontend/`
> 技術棧：React 18 + TypeScript + Redux Toolkit + Ant Design + Vite

---

## 一、路由結構

| 路徑 | 組件 | 說明 |
|---|---|---|
| `/login` | LoginPage | 登入頁（公開） |
| `/` | DashboardPage | 首頁儀表板 |
| `/projects` | ProjectListPage | 專案列表 |
| `/projects/:id` | ProjectDetailPage | 專案詳情 |
| `/review` | ReviewListPage | 審核管理 |
| `/duties` | DutyListPage | AR列表 |
| `/duties/:id` | DutyDetailPage | AR詳情 |
| `/users` | UserManagementPage | 用戶管理 |
| `/search` | SearchPage | 全局搜索 |
| `/statistics` | StatisticsPage | 統計與成員 |
| `/daily-log` | DailyLogPage | 工作日誌 |
| `/anomaly` | AnomalyPage | 異常管理 |
| `/wbs` | WbsOverviewPage | 專案進度總覽（WBS） |
| `/members` | 重定向 → `/statistics` | 成員頁（舊路由） |

所有路由（除 `/login`）均受 `PrivateRoute` 保護，未登入時跳轉至登入頁。

## 三、各頁面功能說明

### 3.1 登入頁（LoginPage）
**功能：** 工號 + 密碼 + 園區登入

| 字段 | 類型 | 說明 |
|---|---|---|
| work_no | 文字輸入 | 員工工號 |
| password | 密碼輸入 | 登入密碼 |
| location | 下拉選擇 | 園區選項（繁簡各 5 個，如鵬鼎園區） |

**API：** `POST /api/user/login`
**登入成功返回：** access_token、work_no、name、role_code、role_name

---

### 3.2 首頁儀表板（DashboardPage）
**功能：** 個人工作概覽，聚合多個數據源

**統計卡片（4 個）**
| 卡片 | 數據來源 |
|---|---|
| 進行中的任務 | `total_task_num.doing_task + doing_duty` |
| 未開始的任務 | `total_task_num.unstart_task + unstart_duty` |
| 待審核 | `total_awaiting_review_num.project + duty` |
| 未讀進度更新 | `total_progress_record_num` |

**其他模塊**
- 今日日誌狀態卡（顯示當日是否已填寫日誌）
- 月度出勤熱力日曆
- 「我的專案」列表（帶進度條）
- 任務異常提醒橫幅（逾期 / 緊急 / 即將到期）
- 主管視角：下屬任務概覽表格

**API：**
- `GET /api/user/index` — 統計卡片數據
- `GET /api/daily_log` — 今日日誌狀態
- `POST /api/project/project_list` — 我的專案列表
- `GET /statistics/member_stats` — 下屬任務數據（主管視角）

---

### 3.3 專案列表（ProjectListPage）
**功能：** 瀏覽、搜尋、過濾、新建專案

**過濾條件**
- 關鍵字搜尋（專案名稱）
- 狀態篩選（草稿 / 立案審核 / 規劃中 / 執行中 / 完結…）
- 專案組篩選

**視圖模式**
- 表格視圖（默認）
- 看板視圖（按狀態分欄）

**表格列：** 專案名稱、狀態、優先級、產品PM、專案PM、進度、預計完成日期、操作

**API：**
- `POST /api/project/project_list` — 列表（分頁）
- `GET /api/project/project_group` — 專案組列表（篩選用）
- `DELETE /api/project/:id` — 刪除專案

---

### 3.4 專案詳情（ProjectDetailPage）
**功能：** 查看專案完整信息，管理功能項、里程碑、甘特圖

**Tab 結構**
| Tab | 功能 |
|---|---|
| 功能清單 | 查看 / 新增 / 刪除功能項（任務） |
| 里程碑 | 設定關鍵里程碑與目標日期 |
| 甘特圖 | 視覺化時間線（GanttChart 組件） |
| 成員動態 | 操作記錄時間軸 |

**功能項操作**
- 新增功能（彈窗：名稱、描述、優先級、開發人員、預計日期、負責組）
- 點擊功能項 → 打開 FunctionDetailDrawer（側抽屜）
- 篩選「我的」/ 「全部」
- 按組分組顯示

**API：**
- `GET /api/project/:id` — 專案詳情
- `POST /api/project/:pid/function_list` — 功能列表
- `POST /api/project/:pid/add_function` — 新增功能
- `DELETE /api/project/:pid/function/:fid` — 刪除功能
- `GET /api/project/:id/milestones` — 里程碑列表
- `POST/PUT/DELETE /api/project/:pid/milestones/:mid` — 里程碑 CRUD
- `GET /api/project/:id/gantt_chart` — 甘特圖數據
- `GET /api/project/:id/member_dynamics` — 成員動態

---

### 3.5 審核管理（ReviewListPage）
**功能：** 審核流程管理，支持多節點審批鏈、加簽

**Tab 分類**
| Tab | 說明 |
|---|---|
| 立案審核 | 專案啟動申請 |
| 規劃審核 | 專案規劃確認 |
| 功能完結 | 單個功能完成審核 |
| 專案完結 | 整體專案完成審核 |
| 任務完結 | AR完成審核 |
| 已完成 | 歷史審核記錄 |

**審批鏈可視化**
- 每個審核單顯示所有審批節點（有序）
- 當前待審節點高亮動畫
- 支持通過 / 拒絕 / 退回
- 支持加簽（countersign）

**API：**
- `GET /api/project/review_list` — 專案審核列表
- `GET /api/temporary_duty/review_list` — 任務審核列表
- `PUT /api/project/review/:id` — 審批操作（通過 / 拒絕 / 退回）
- `PUT /api/temporary_duty/review/:id` — 任務審批
- `POST /api/project/review/:id/countersign` — 加簽
- `POST /api/temporary_duty/review/:id/countersign` — 任務加簽

### 3.12 異常管理（AnomalyPage）
**功能：** 彙總系統中各類異常問題，按風險等級分類展示

**異常類型**
| 類型 | 說明 |
|---|---|
| 任務逾期 | 已超過預計完成日期 |
| 任務緊急 | 即將到期（3 天內） |
| 無日誌 | 連續多天未填工作日誌 |
| 工時不足 | 日均工時低於標準 |

**風險等級：** critical（紅）/ warning（橙）/ info（藍）

## 四、Redux Store 結構

```
store
├── auth
│   ├── token: string | null          # JWT Token（同步至 localStorage）
│   ├── workNo: string | null          # 工號
│   ├── name: string | null            # 姓名
│   ├── indexData: UserIndexContent | null  # 首頁統計數據
│   ├── isLoading: boolean
│   └── error: string | null
│
├── user
│   ├── list: UserProfile[]            # 用戶列表
│   ├── totalCount: number
│   ├── departments: string[]          # 部門列表
│   ├── current: UserProfile | null
│   ├── isLoading: boolean
│   └── isSaving: boolean
│
├── project
│   ├── list: ProjectListItem[]
│   ├── totalCount / totalPage: number
│   ├── current: Project | null        # 當前詳情
│   ├── groups: ProjectGroup[]         # 專案組
│   ├── query: ProjectListQuery        # 當前篩選條件
│   ├── isLoading / isSaving: boolean
│   └── error: string | null
│
└── duty
    ├── list: TemporaryDuty[]
    ├── totalCount / totalPage: number
    ├── current: TemporaryDuty | null
    ├── query: DutyListQuery
    ├── isLoading / isSaving: boolean
    └── error: string | null
```

## 七、需要注意的問題

1. **`/api/user/index` 返回字段**
   後端實際返回：`total_task_num`、`total_progress_record_num`、`total_awaiting_review_num`
   前端 `UserIndexContent` 類型已修正對齊。

2. **登入 location 字段**
   後端 `LogInSchema` 嚴格驗證 location 必須為指定園區名稱（如 `鵬鼎園區`），前端已修正。

3. **HTTP 響應碼**
   後端成功碼為 `"S10000"`，失敗碼為 `"F10001"`，前端 `httpClient.ts` 已配置正確。

4. **JWT Token 格式**
   Token 的 `sub` 字段為 dict：`{empid, username, role_code, location}`。

5. **Mock 數據**
   `auth.api.ts` 中的 `IS_DEV` mock 登入邏輯已全部移除，所有接口均調用真實後端。
